# My Contributions

This is a fork of [original-owner/PlayVision](https://github.com/ishit-10/football_player_stats_tracker),
a team project. This file covers only the parts I worked on.

## What I worked on

### Metrics and data pipelines
- Built NumPy and Pandas pipelines that turn tracked player and ball positions
  into performance metrics such as ball possession, player speed and territory control
- Cleaned and structured the tracking output so it could be used for analysis
  and dashboards

### Model optimisation
- Optimised the YOLO detection models to reduce inference latency, helping the
  system run in real time
- Tuned the pipeline so detection, tracking and metric computation could keep up
  with video frame rates

### Dashboards
- Built interactive dashboards that present the metrics in a form coaches and
  analysts can read and use

## Tech used
Python, YOLO, PyTorch, OpenCV, NumPy, Pandas
